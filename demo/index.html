Watching the tree reason

A scripted walkthrough of the ToT-MARL pipeline on a dummy contract dispute — no model calls, no API key, just the architecture in motion. Three scouts who can't see each other's facts, a reasoner that branches into competing theories, a critic that prunes the weak ones, and a synthesis that never saw the raw case.

The scoring step below is the one piece of this project meant to be replaced by a trained policy someday — see the design doc for why.
